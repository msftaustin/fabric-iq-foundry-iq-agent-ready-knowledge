# Technical source

The live demo implementation remains in the repository's [`notebooks/`](../../../notebooks/)
folder so the established provisioning scripts and relative paths continue to work.

Start with
[`part1-standard-foundry-iq-kb.ipynb`](../../../notebooks/part1-standard-foundry-iq-kb.ipynb)
and run Parts 1 and 3 for the core Azure+Fabric story. Follow
[`DEMO_SETUP.md`](../../../DEMO_SETUP.md) before provisioning. Parts 2, 4, and 5 are optional
and require additional tenant capabilities.
